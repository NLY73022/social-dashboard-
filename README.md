# Digital Campus Dashboard — Topic 6

Interactive Social Network & Spatial Regression Dashboard for
*The Digital Campus: Algorithmic Enclaves, Social Comparison, and the
Hybrid Spatialities of Student Life in Kampala*.

## What it does

- **Network graph tab** — visualizes the structural architecture of student
  digital enclaves (WhatsApp groups, X circles, TikTok hubs, Instagram),
  colored by active (green) vs passive (grey) usage mode, filterable by platform.
- **Geospatial heatmap tab** — overlays self-reported digital activity intensity
  onto physical campus locations (library, hostels, lecture halls, etc.)
  to show where digital and physical spaces most heavily intersect.
- **Summary stat cards** — respondent count, average screen time, and
  isolation-risk flag rate, pulled live from the data.

## Setup

```bash
cd social_dashboard
pip install -r requirements.txt
python app.py
```

Then open **http://127.0.0.1:8050** in a browser.

## Swapping in real survey data

The app currently runs on **synthetic placeholder data** generated by
`data/generate_sample_data.py`, so the group can build and test the
dashboard before data collection finishes.

To plug in real data, replace these three files with the same column
structure:

| File | Required columns |
|---|---|
| `data/survey_data.csv` | `student_id, location_id, primary_platform, usage_mode, daily_screen_time_hrs, loneliness_score, dass21_score, isolation_flag` |
| `data/locations.csv` | `location_id, location_name, lat, lon` |
| `data/network_edges.csv` | `source, target, platform, weight` |

Notes:
- `usage_mode` must be exactly `"active"` or `"passive"` (maps to the
  brief's active-production vs passive-consumption split).
- `lat`/`lon` should be real GPS coordinates for your campus locations —
  update `data/locations.csv` with your actual buildings.
- `network_edges.csv` should come from your virtual enclave ethnography
  (Step 2 of the workflow) — e.g., who replies to whom in a WhatsApp
  group, who shares each other's TikToks, mutual follows on X.
- `loneliness_score` (UCLA Loneliness Scale) and `dass21_score` (DASS-21)
  are included so you can extend the dashboard with the spatial
  regression analysis later (e.g., a scatter/regression tab plotting
  screen time or enclave centrality against these scores).

No code changes are needed if column names match — just re-run the app.

## Extending for the "spatial regression" part of the deliverable

The current build covers the two required visuals (network graph +
geospatial heatmap). To add the regression analysis itself, a good next
step is a third tab with a scatter plot (e.g., `plotly.express.scatter`
with a trendline) of screen time or network centrality vs. loneliness/DASS-21
scores, using `statsmodels` for the regression line.
